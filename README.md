# CroweSync

Overlays, alerts and chat for TikTok LIVE and Twitch, for Windows. By Sevrin Crowe.

**Download: https://sev-wr.itch.io/crowesync**

This repository only hosts release files and `latest.json`, the feed CroweSync reads to update itself. Installed copies download the newest installer from the latest release, check its SHA-256 fingerprint and install it when the app closes (never during a live).

CroweSync is unofficial and not affiliated with or endorsed by TikTok, ByteDance or Twitch.
